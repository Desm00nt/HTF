# Atria Dawn Chat — Minecraft Forge 1.19.2 mod

Полностью **автономный мод** (никак не зависит от других модов): общайтесь с
нейросетевой моделью **[Atria Dawn](https://github.com/atria-asi/Atria-Dawn-Preview)**
прямо в игровом чате — **на русском языке**. Работает в одиночной игре и на
сервере, в любом мире.

## Возможности

| Способ | Пример |
| --- | --- |
| Префикс в чате | `@как скрафтить печь?` — Atria Dawn ответит в чате |
| Команда | `/atria привет, кто ты?` |
| Сброс контекста | `/atria reset` |
| Справка | `/atria about` |
| Ввод API-ключа в игре | `/atria key atr_ВАШ_КЛЮЧ` |
| Проверка ключа | `/atria key status` (показывается замаскированным) |
| Удаление ключа | `/atria key clear` |
| Перечитать конфиг | `/atria reload` (операторы) |

- **Память диалога:** бот помнит 20 последних реплик (настраивается), у каждого
  игрока — своя история; можно уточнять: «а почему?», «а на сервере?».
- **Кулдаун** 3 секунды между вопросами, индикатор «Atria Dawn печатает...».
- **Асинхронные запросы** — сервер не подвисает во время ответа нейросети;
  длинные ответы аккуратно режутся на части.
- **Локализация:** русский и английский (`assets/atriadawn/lang`).
- Префикс-триггер и всё поведение настраиваются в `config/atriadawn.json`.

## Установка

1. Положите `atriadawn-1.3.0.jar` в папку `mods/` (Minecraft **1.19.2** +
   Forge **43.4.0** и новее в пределах 1.19.x).
2. Запустите игру (в одиночном мире включите читы, чтобы пользоваться
   командами оператора).

## Настройка (один раз)

1. Получите API-ключ в консоли Atria (ключи вида `atr_...`).
2. В игре выполните:
   ```
   /atria key atr_ВАШ_КЛЮЧ
   ```
   Ключ сохранится в `config/atriadawn.json` и применится сразу — перезагрузка
   не нужна. Можно и просто отредактировать файл руками, затем `/atria reload`.
3. Пишите боту: `@привет! кто ты?` или `/atria <сообщение>`.

По умолчанию мод обращается к официальному OpenAI-совместимому API
`https://api.atria-asi.ai/v1/chat/completions` (модель `Atria-Dawn-Preview`).
Подойдёт **любой совместимый сервис** (OpenRouter, ollama, llama.cpp server,
OpenAI и т.п.) — поменяйте `apiUrl`, `model` и `apiKey` в конфиге:

```json
{
    "apiUrl": "https://api.atria-asi.ai/v1/chat/completions",
    "apiKey": "",
    "apiKeyEnvVar": "ATRIA_API_KEY",
    "model": "Atria-Dawn-Preview",
    "chatPrefix": "@",
    "systemPrompt": "Ты — Atria Dawn, дружелюбная ИИ-спутница игроков Minecraft. ...",
    "temperature": 0.8,
    "maxTokens": 1024,
    "requestTimeoutSeconds": 120,
    "cooldownSeconds": 3,
    "maxHistoryMessages": 20,
    "maxResponseChars": 700,
    "showTypingIndicator": true,
    "broadcastReplies": false
}
```

| Параметр | Описание |
| --- | --- |
| `apiUrl` | URL Chat Completions эндпоинта |
| `apiKey` | API-ключ (можно задать и командой `/atria key`) |
| `apiKeyEnvVar` | Переменная окружения с ключом (запасной способ) |
| `chatPrefix` | Префикс-триггер в чате; пустая строка = отключить |
| `systemPrompt` | Характер бота; `%player%` заменяется на ник игрока |
| `temperature`, `maxTokens` | Параметры сэмплирования модели |
| `cooldownSeconds` | Антиспам-пауза между вопросами |
| `maxHistoryMessages` | Сколько реплик диалога помнить |
| `maxResponseChars` | Максимальная длина одного сообщения в чате |
| `broadcastReplies` | `true` — отвечать всем игрокам сервера |
| `logTriggers` | `true` — писать в лог каждый триггер и каждую отправку (диагностика ложных срабатываний) |

## 🤖 Агент-компаньон (v1.1.0+, расширен в v1.2.0)

Atria может принять **тело-аватар в мире** и выполнять задачи как агент:
ходить, добывать блоки, приносить ресурсы, ставить блоки, драться с мобами.

1. Призовите тело: **`/atria summon`**
2. Дайте задачу: **`/atriaagent добудь 10 булыжника и принеси мне`** (или построй маленький домик 3x3)
3. Она сама спланирует шаги: осмотрится (`scan_area`), пойдёт (`walk_to`), докопает (`mine_block`),
   поставит (`place_block`), отобьётся от мобов (`attack_nearest`) — и отчитается.
4. `/atriaagent stop` — прервать; ПКМ по компаньону — вкл/выкл следование.

Механика: нейросети передаётся список «инструментов» (OpenAI tool use);
если модель отвечает обычным текстом, мод понимает и формат
`{"tool": "...", "args": {...}}` прямо в тексте. Результат каждого действия
возвращается модели, и цикл повторяется до `finish` (лимит шагов и таймаут
настраиваются). Тело имеет свой инвентарь (9 слотов): добыча падает туда,
блоки для постройки берутся оттуда.

**Новое в v1.2.0:**
- `craft_item` — крафт по реальным рецептам сервера из своего инвентаря;
  рецепты до 4 ингредиентов — «в руках», для сложных нужен верстак в 3 блоках
  (агент может сам скрафтить доски → верстак → поставить → крафтить у него);
- `give_to_player` — передать вам добычу (замыкает цикл «добудь и принеси»);
- автопоедание: при ранениях компаньон ест еду из инвентаря (`agentAutoEat`);
- телепорт к владельцу, если отстала дальше ~40 блоков (`agentStuckTeleport`);
- память: итоги задач попадают в историю чата — `@что ты сейчас делала?` работает.

**Новое в v1.3.0:**
- `smelt_item` — переплавка в печке (печка в 3 блоках + топливо, 1 топливо = 1 переплавка);
  агент умеет сам построить печку из булыжника и переплавить руду в слитки;
- `use_chest` — сдавать добычу в сундук и забирать предметы из него (deposit/withdraw);
- `guard_mode` — режим охраны: в простое атакует враждебных мобов в радиусе 8 блоков.

Ограничения и безопасность (конфиг): `agentEnabled`, `agentMaxIterations` (12),
`agentActionRadius` (48 блоков от владельца), `agentCanBreakBlocks`,
`agentCanPlaceBlocks`, `agentTaskTimeoutSeconds` (300), `agentAutoEat`,
`agentStuckTeleport`. Качество агента зависит
от модели: агентные модели (tool use) справляются с задачами заметно лучше.

## Сборка jar

**Вручную:** нужен JDK 17 — затем `./gradlew build` (готовый jar появится в
`build/libs/atriadawn-1.3.0.jar`).

**Без локальной сборки:** корневой CI этого репозитория собирает мод вместе с
How To Fish. Артефакт `howtofish-mod` (вкладка **Actions** → зелёный запуск →
**Artifacts**) содержит `howtofish-1.0.0.jar`, **внутри которого** лежит готовый
`atriadawn-1.3.0.jar` и `atriadawn-canary.txt`: откройте jar любым архиватором
(7-Zip / WinRAR / `unzip`) и извлеките `atriadawn-1.3.0.jar` в папку `mods/`.

> Если вынесете мод в отдельный репозиторий — скопируйте **содержимое** этой
> папки в его корень: внутри уже лежит собственный workflow
> `atriadawn-mod/.github/workflows/build.yml`, а хук в корневом `build.gradle`
> монорепозитория сам перестанет срабатывать (у него есть проверка наличия папки).

## Структура

```
atriadawn-mod/
├── build.gradle, gradle.properties      # ForgeGradle 5 (Minecraft 1.19.2)
├── gradlew, gradle/wrapper/             # Gradle wrapper 7.5.1
├── .github/workflows/build.yml          # CI (когда папка — корень своего репозитория)
└── src/main/
    ├── java/com/atriadawn/mod/          # весь код мода (7 классов)
    │   ├── AtriaDawnMod.java            # точка входа (@Mod "atriadawn")
    │   ├── AtriaEvents.java             # перехват чата (@) + регистрация /atria
    │   ├── AtriaCommands.java           # /atria, /atria key, /atria reset ...
    │   ├── AtriaChatManager.java        # кулдауны, «печатает...», доставка ответов
    │   ├── AtriaApiClient.java          # асинхронный HTTP-клиент (java.net.http)
    │   ├── AtriaConversation.java       # память диалога по игрокам
    │   └── AtriaConfig.java             # config/atriadawn.json
    └── resources/
        ├── META-INF/mods.toml, pack.mcmeta
        └── assets/atriadawn/lang/       # ru_ru.json, en_us.json
```

Дополнительных библиотек не требуется — JSON обрабатывается штатным Gson из
Minecraft, HTTP — стандартным `java.net.http` (Java 17).

## Замечания

- ⚠️ Вопросы отправляются на внешний API — не пишите боту пароли и личные
  данные. API-ключ хранится в `config/atriadawn.json` в открытом виде.
- Вводить ключ могут операторы сервера (уровень прав 2) и владелец
  одиночного мира (читы включать не обязательно, начиная с версии 1.0.3).

## Частые проблемы

**«Неверный аргумент для команды» при вводе `/atria key <ключ>`, команда
«не вводится»**
Это значит, что узел команды для вас скрыт: у вас нет прав оператора.
В версии **1.0.2+** владелец одиночного мира может вводить ключ без читов —
обновите мод. На сервере попросите оператора выполнить `/atria key <ключ>`
или выдать вам права (`/op <ник>`).

**Бот молчит / «нет API-ключа»**
Проверьте `/atria key status`. Если ключ задан, но ошибок нет и ответов тоже —
смотрите лог сервера/игры: там подробно пишутся ошибки сети и API.

**Бот отвечает на отдельные буквы / спамит запросами при наборе текста**
Так бывает из-за ванильного «Предпросмотра чата» (Chat Preview): клиент шлёт
серверу заготовку на каждое нажатие клавиши. Мод (с версии 1.0.2) сам
выключает предпросмотр при входе в мир и дополнительно «допечатывает» за вами:
сообщение уходит только после паузы ~1,2 с, побеждает последний вариант текста,
обрывки короче 3 символов игнорируются. Если нужно вручную: Настройки →
Настройки чата → «Предпросмотр чата» → Выкл. На выделенном сервере также
помогает `previews-chat=false` в server.properties.
Если подозреваете, что запросы всё равно уходят без нажатия Enter — включите
в конфиге `"logTriggers": true`, выполните `/atria reload` и посмотрите
`latest.log`: там с метками времени видно каждый триггер (`Atria trigger`)
и каждую реальную отправку (`Atria send`). Пришлите эти строки — разберёмся.
- `/atria key status` никогда не показывает ключ целиком — только маску
  вида `atr_3f...9c2d`.
